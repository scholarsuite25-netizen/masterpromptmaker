# Master Prompt Studio (masterpromptmaker)

A world-class prompt engineering workbench, autonomous 30-mode digital content factory, and digital creator marketplace built for high-performance AI creators, consultants, and teams.

## 🚀 Key Features

- **Prompt Engineering Workbench**:
  - Live AI prompt builder with dual-format export (Clean vs. Markdown).
  - Variable and placeholder detection (`{{variable}}` syntax).
  - Framework selector (RTF, TAG, CARE, BAB, RISEN, etc.).
  - Readability score & optimization suggestions.
  - One-click copy, quick test run, and instant download.
- **Autonomous Digital Content Factory (30 Modes)**:
  - Multi-category content synthesis across Copywriting, Video/Scripting, Academic & Research, Developer Docs, Business Strategy, Social Media & Viral Growth, Marketing Funnels, and more.
  - Preset quick-injection and customizable variables.
- **Digital Creator Store & Marketplace**:
  - 8 core digital product categories: Prompts, Ebooks, Notion Templates, Video Courses, Design Assets, Audio Presets, Workbooks, and SaaS Toolkits.

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 8
- **Icons**: Lucide React
- **Animations / FX**: Canvas Confetti & Glassmorphism UI
- **Styling**: Tailored Modern HSL CSS Design System with Dark Mode
- **Deployment**: Vercel

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
