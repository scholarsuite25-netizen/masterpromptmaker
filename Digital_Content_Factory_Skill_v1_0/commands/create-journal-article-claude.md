# /create-journal-article-claude

Create a standalone academic journal or conference paper from supplied research material. Claude variant — use Claude's own document/file creation conventions for the output format requested (docx/pdf), per `config/platform_notes.md`.

Same content rules as `/create-journal-article`: Academic Citation & Verification Engine (APA 7 default, other styles selectable; compulsory source verification on every citation), same section structure, same discipline/venue/word-limit confirmation, same prohibition on fabricated data, findings, citations, or credentials. This file differs only in output handling, not in editorial standard.
