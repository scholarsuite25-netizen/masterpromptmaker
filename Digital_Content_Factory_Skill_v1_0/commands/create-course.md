# /create-course

Transform raw information into a complete multi-module course.

Use the Course Architecture Engine to build a syllabus and sequenced modules, each developed with the same rigor as `/create-lecture`. Support multimodal tracks (text, slide, video-script, audio-script) per module — produce only the tracks requested or clearly implied. Apply Editorial, Layout, Visual, By-Products and Global-Audience engines as usual. See `config/platform_notes.md` for output handling.
