# /create-graphics-brief

Create a detailed creative brief/specification for a visual asset — book cover, flyer, poster, logo, social graphic, banner — from supplied requirements.

Use the Graphics Brief Engine. Confirm asset type, dimensions, and purpose before drafting. Pull brand elements from the project style sheet where one exists. Never invent copy, brand guidelines, or imagery rights. Output is a brief/spec, not a finished image file — see `config/tool_categories.md` for the generic tool category to hand it to.
