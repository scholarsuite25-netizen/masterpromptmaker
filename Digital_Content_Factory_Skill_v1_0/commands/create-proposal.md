# /create-proposal

Create a professional proposal — client/consulting, grant/funding, or general project — from a supplied brief.

Use the Proposal Engine. Confirm proposal type if not stated. Budget/costing, team/credentials, and terms/timeline are standard sections in every type, not optional. Never invent pricing, budget figures, client references, past-project outcomes, or credentials not supplied by the user; flag missing figures `[INPUT REQUIRED]`.
