# /create-video

Create a video script, storyboard, or shot list from supplied requirements.

Use the Audio, Music & Video Engine (video track). Confirm video type (tutorial/screen-recording, talking-head, promotional, animated explainer), platform/aspect ratio, and runtime target before drafting. For tutorial-accompanying video, align steps with the Tutorial Engine. Output is a script/storyboard, not a finished video file — see `config/tool_categories.md`. Never fabricate real-person likeness/voice claims or licensing.
