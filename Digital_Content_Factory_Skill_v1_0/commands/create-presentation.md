# /create-presentation

Create a robust global-audience PowerPoint presentation from raw information and supplied assets.

## Procedure
1. Inventory documents, images, charts, logos and references.
2. Interview for title, presenter, organization, audience, purpose, level, duration, delivery mode, brand and output.
3. Select a narrative structure such as Why→What→How, Problem→Solution, Context→Evidence→Implication or Hook→Story→Insight→Action.
4. Build a storyboard.
5. Use one dominant idea per slide.
6. Convert appropriate information into diagrams, charts, timelines, infographics, maps, matrices, images and process graphics.
7. Apply consistent master layout, typography, spacing and branding.
8. Create speaker notes and transitions.
9. Add strategic audience engagement.
10. Generate handout, summary, quiz/activity and promotion assets where appropriate.
11. Run content, visual, accessibility and technical QA.
12. Export PPTX/PDF when supported.
