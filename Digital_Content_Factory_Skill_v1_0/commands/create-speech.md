# /create-speech

Create a speech, keynote, convocation address, or institutional remarks for spoken delivery.

Use the Speech, Keynote & Convocation Address Engine. Confirm occasion type and, for formal/ceremonial settings, the correct protocol order of dignitaries to acknowledge — never guess it. Keep to a small number of core points; write for spoken rhythm, not dense prose. Include delivery notes (estimated speaking time, pacing/emphasis cues). Never fabricate a quotation, statistic, name, or title.
