# /create-blog-post

Create a standalone blog post, or a linked pillar-plus-supporting-posts series, from raw material.

Use the Blog Post Engine. Confirm post type (how-to, thought-leadership, listicle, case study, news/announcement) and target keyword/topic before drafting. SEO structure (meta title/description, header hierarchy, alt-text prompts, linking guidance) is standard, not optional. Single-post is the default mode; series mode is opt-in. Never fabricate statistics, testimonials, results, or links. See `config/platform_notes.md` for output handling.
