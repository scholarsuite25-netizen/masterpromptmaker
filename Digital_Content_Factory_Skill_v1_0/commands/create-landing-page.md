# /create-landing-page

Create a conversion-focused landing page for any offer — product, service, course, event, or app signup.

Use the Global Landing Page Engine. One primary conversion goal per page. Standard SEO section applies as in the Blog Post Engine. Never fabricate testimonials, numbers, or unverified links — flag `[INPUT REQUIRED]` / `[LINK VERIFICATION REQUIRED]` instead. Hand visual needs to the Graphics Brief Engine. See `config/tool_categories.md` for the generic website/page-builder tool category.
