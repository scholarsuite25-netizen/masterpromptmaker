# /create-audio-music

Create a narration script or music/audio production spec from supplied requirements.

Use the Audio, Music & Video Engine (audio/music track). Confirm purpose (narration vs. music), duration, and tone before drafting. Output is a script/spec, not a finished audio file — see `config/tool_categories.md` for the generic tool category to hand it to. Never fabricate voice-talent credentials or licensing claims.
