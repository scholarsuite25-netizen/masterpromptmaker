# /create-guided-journal

Create a personal/reflective guided-journal product from a stated theme or purpose.

Use the Guided Journal Engine. Establish theme, structure (thematic or time-based), and recurring elements (trackers, review checkpoints) with the user before drafting. Keep prompts supportive, open-ended and non-diagnostic. Apply Layout, Visual and Global-Audience engines as usual; the Academic Citation/Verification engines do not apply to this command.
