# /create-email-campaign

Create a marketing/lifecycle email or a linked email sequence from supplied material.

Use the Email Marketing Engine. Confirm email type (announcement, welcome sequence, nurture, retention, reactivation, promotional) before drafting. Compliance footer (unsubscribe, sender identity) is standard, not optional — flag `[INPUT REQUIRED]` if not supplied. Never fabricate personalization data, testimonials, or urgency claims. Drafts content only; does not send anything.
