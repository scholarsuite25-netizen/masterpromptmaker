# /create-newsletter

Create a complete professional newsletter from supplied raw documents and assets.

## Procedure
1. Inventory documents, images, logo and previous issues.
2. Interview for newsletter name, masthead, audience, purpose, frequency, issue/date, tone, brand and outputs.
3. Build issue architecture.
4. Classify material into lead story, featured news, briefs, events, people, announcements, interviews and supporting elements.
5. Edit and structure stories.
6. Add appropriate sidebars, fact boxes, pull quotes, captions and calls to action.
7. Apply grid, typography and image treatment.
8. Support mixed columns and text wrapping.
9. Generate web/email/social derivatives.
10. Run publication QA and finalize.
