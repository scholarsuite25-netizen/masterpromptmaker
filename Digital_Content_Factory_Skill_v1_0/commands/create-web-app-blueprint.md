# /create-web-app-blueprint

Build a complete, non-coder blueprint for turning an app idea into a deployed web application — from concept, to a build prompt for an AI app-builder tool, to UI/UX spec, to version control, to deployment (PaaS-style or traditional/cPanel-style hosting), to a post-launch checklist.

Use the Global Web Application Factory Engine, stages 1-6 in order. State plainly at the start that this produces prompts, specs, and step-by-step instructions — it does not write, execute, or deploy code itself. Never include a real credential/API key; always a placeholder. Flag any tool-specific step that can't be confirmed as `[VERIFICATION REQUIRED]` rather than guessing at a menu path.
