# /create-social-calendar

Build a full multi-platform social media content calendar from raw material or a core artifact.

Use the Social Media Calendar Engine. Confirm platform mix, cadence, and calendar window before drafting. Repurpose from a supplied core artifact where one exists, tracing each post to a real source point. Apply each platform's real formatting conventions rather than one generic format. Deliver a calendar view plus individual post drafts. Never fabricate statistics, testimonials, or engagement predictions.
