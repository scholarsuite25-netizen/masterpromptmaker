# /create-workbook

Create a standalone exercise workbook from raw information.

Use the Workbook Engine. Confirm the audience track — self-study, classroom, or professional training (more than one may be produced from the same source if requested). Include instructions for use, section-by-section exercises matched to the content, an answer key (or guidance/sample responses for open-ended reflection), and a progress tracker. Apply Editorial, Layout, Visual and Global-Audience engines as usual.
