# /create-journal-article

Create a standalone academic journal or conference paper from supplied research material. Portable variant — for ChatGPT, Gemini, or Claude without platform-specific output handling.

Use the Academic Citation & Verification Engine (APA 7 default, other styles selectable; compulsory source verification on every citation). Structure: title, author/affiliation block (as supplied), abstract, keywords, introduction, literature review, methodology, results, discussion, conclusion, references, appendices as needed — adjust section names to the target journal/conference's own template if the user supplies one. Ask discipline, target venue, and word-limit before drafting if not stated. Never fabricate data, findings, citations, or credentials. See `config/platform_notes.md` for output handling.
