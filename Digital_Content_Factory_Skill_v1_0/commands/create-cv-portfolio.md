# /create-cv-portfolio

Create a CV/résumé, a full job-application package, and/or a portfolio (website, document, or both) from supplied candidate material.

Use the Global CV & Portfolio Engine. Confirm CV/résumé format before drafting — academic, institutional leadership, chronological, functional, combination, executive, entry-level/graduate, or other (see engine for the full list and corresponding `templates/` file for each). If a job advert/vacancy announcement is supplied, tailor emphasis to its stated criteria without inventing experience. For institutional leadership applications, include a Statement of Vision/Intent where the vacancy calls for one. Portfolio track may be website, document, or both. Never fabricate qualifications, history, achievements, or referee details. Applies Global-Audience formatting by default.
