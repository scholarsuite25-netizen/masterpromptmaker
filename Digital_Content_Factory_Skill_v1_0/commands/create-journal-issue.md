# /create-journal-issue

Compile supplied articles into a formatted academic journal issue.

Use the Academic Journal Engine and the Academic Citation & Verification Engine (compulsory source verification applies to every citation in every article). Build table of contents, editorial/foreword, consistent cross-article formatting, and per-article metadata tracking. Never perform, simulate, or fabricate peer review; never invent DOIs, ISSNs, or volume/issue numbers not supplied.
