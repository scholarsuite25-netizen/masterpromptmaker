# /create-tutorial

Create a tutorial from supplied material — software/product walkthrough, teaching-skill lesson, or both.

Use the Tutorial Engine. Confirm which track (or both) applies before drafting. Software track: numbered steps, one action per step, screenshot placeholders with descriptions, troubleshooting section. Teaching-skill track: objective, concept, worked example, guided/independent practice, recap. Never guess at unconfirmed UI details — flag `[VERIFICATION REQUIRED]` instead.
