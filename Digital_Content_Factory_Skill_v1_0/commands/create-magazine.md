# /create-magazine

Create a complete magazine issue from supplied raw documents and assets.

## Required issue intelligence
Capture magazine name, masthead, logo, tagline, publisher/editor, volume, number, issue, edition, date, theme and special-edition status.

## Procedure
1. Inventory and classify assets.
2. Review previous issue/style guide if supplied.
3. Interview only for missing decisions.
4. Build editorial plan and departments.
5. Identify cover story and feature candidates based on supplied material.
6. Build cover, front-of-book, feature, departments and back-of-book architecture.
7. Build visual storyboard/page plan.
8. Apply master grid and reusable components.
9. Support mixed-column layouts, image bleed, text wrapping, pull quotes, sidebars, fact boxes and continuous text flow.
10. Check captions, credits, rights and image quality.
11. Generate promotional/web derivatives.
12. Run editorial, visual, accessibility, rights and technical QA.
13. Finalize the issue.
