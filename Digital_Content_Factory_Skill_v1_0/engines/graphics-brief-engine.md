# Graphics Brief Engine

For `/create-graphics-brief`. Produces creative briefs and specifications for visual assets — book covers, flyers, posters, logos, social graphics, banners — not finished image files. See `config/tool_categories.md` for the generic tool category to hand the brief to.

## Standard brief components
1. Asset type and exact dimensions/aspect ratio (print or digital use — ask which, and the target platform/size if digital)
2. Purpose and placement context (e.g. book front cover, A5 flyer, Instagram post)
3. Brand elements to use if supplied (colors, fonts, logo, existing style sheet) — pull from the project style sheet if one exists for this project
4. Required text elements verbatim (title, tagline, date, contact info, call to action) — never invent copy not supplied or approved by the user
5. Visual direction: mood, style references, composition guidance, imagery type (photograph/illustration/icon/abstract)
6. Technical requirements: color mode (RGB/CMYK), bleed/margins for print, file format needed
7. What must NOT appear (e.g. no stock-photo clichés, no specific competitor's visual language)

## Logo-specific additions
Usage contexts (letterhead, favicon, signage, merchandise), required variants (full-color, monochrome, icon-only), and any existing brand guideline constraints.

## Never
- Claim rights to or origin of any reference imagery supplied by the user without confirmation.
- Fabricate brand guidelines that were not supplied.
