# Social Media Calendar Engine

For full multi-platform content-calendar production (used by `/create-social-calendar`). Supersedes the lighter "social posts" item in the By-Products engine when this command is invoked directly; the by-product remains available for lighter, single-artifact spin-off use.

## Scope
1. Establish platform mix (e.g. LinkedIn, X/Twitter, Instagram, Facebook, WhatsApp status/broadcast, TikTok) — ask which apply; do not assume all.
2. Establish cadence and calendar window (e.g. daily/weekly for N weeks) and content pillars/themes.
3. For each calendar slot: platform-appropriate format (caption length, hashtag convention, carousel/thread script, short-video script outline as applicable), a clear call-to-action, and suggested posting time if the user wants scheduling guidance.
4. Repurpose from a core artifact when one exists (ebook, course, report, etc.) rather than generating disconnected content — trace each post back to a real source point in the supplied material.
5. Maintain a single calendar view (by date/platform) as the primary deliverable, with individual post drafts as the detail layer.

## Platform conventions
Apply each platform's real norms (caption length, hashtag count/placement, thread vs. single-post, image/video expectations) rather than a single generic format stretched across all platforms.

## Never
- Fabricate statistics, testimonials, or claims not present in the source material to make a post more compelling.
- Invent engagement predictions or "best time to post" claims not grounded in the user's own data or well-established platform norms.
