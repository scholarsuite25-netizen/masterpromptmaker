# Proposal Engine

For `/create-proposal`. Covers all three proposal types from one command; the type determines which standard sections are emphasized, but budget/costing, team/credentials, and terms/timeline are standard (non-optional) sections in every type.

## Proposal types
- **Client/consulting service proposal** — scope of work, deliverables, methodology/approach, pricing, timeline, team, terms.
- **Grant/funding proposal** — problem statement, objectives, methodology/work plan, budget justification, expected impact/outcomes, evaluation plan, team, timeline.
- **General project proposal** — problem/opportunity, objectives, approach, resource requirements, timeline, team, expected outcomes.

Ask which type applies before drafting if not stated or obvious from supplied material.

## Standard sections (all types)
1. Cover/title page
2. Executive summary
3. Problem/need or opportunity statement
4. Objectives/scope of work
5. Approach/methodology
6. Timeline (phased if the engagement has phases)
7. Budget/costing (line-itemized where figures are supplied; flagged `[INPUT REQUIRED]` where they are not — never invent figures)
8. Team/credentials (only credentials actually supplied by the user — never invent qualifications, past projects, or client names)
9. Terms (payment terms, validity period, assumptions/exclusions)
10. Appendices as needed (CVs, past work samples, references) if supplied

## Never
- Invent pricing, budget figures, client references, past-project outcomes, or credentials not supplied by the user.
- Present a boilerplate methodology as if tailored to the specific opportunity without adapting it to the supplied brief.
