# Workbook Engine

For standalone exercise workbooks (used by `/create-workbook`). Distinct from the "learner pack" by-product: a workbook is a primary deliverable in its own right, not a derivative of another artifact.

## Audience tracks (select one, or the user may request more than one from the same source material)
- **Self-study** — individually paced; includes worked examples, self-check answers, and guidance notes a facilitator would normally supply live.
- **Classroom** — designed for facilitator-led use; lighter on self-explanation, includes facilitator cues and suggested pacing/timing per section.
- **Professional training** — outcome/competency framed; includes workplace-application exercises and a completion/certification checklist if applicable.

## Standard components
- Instructions for use
- Section-by-section exercises (mixed types: fill-in, short answer, scenario/case, reflection, practical task — select what fits the content, do not force every type into every section)
- Space/structure for written responses where the output format supports it
- Answer key (self-study and professional tracks by default; classroom track by facilitator preference — ask)
- Progress tracker or completion checklist

## Never
- Produce answer keys with fabricated "correct" answers for open-ended reflection exercises — mark these as guidance/sample responses, not answer keys.
