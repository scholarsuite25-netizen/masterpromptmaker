# Thesis/Dissertation Structure Engine

For `/create-thesis` and `/create-thesis-claude`.

## Default skeleton: Nigerian university format
Used automatically unless the user supplies their own institutional template, in which case the supplied template takes precedence entirely (do not blend the two).

**Front matter:** Title page, Declaration, Certification, Dedication (optional), Acknowledgement, Abstract, Table of Contents, List of Tables, List of Figures, List of Abbreviations/Acronyms (if applicable).

**Main body (by degree level — confirm which before drafting):**
- Undergraduate (BSc/BA project): Chapter 1 Introduction (background, problem statement, objectives, research questions/hypotheses, significance, scope, limitations, definitions) → Chapter 2 Literature Review → Chapter 3 Methodology → Chapter 4 Results/Data Presentation and Analysis → Chapter 5 Summary, Conclusion and Recommendations.
- Masters: same five-chapter structure with greater methodological and theoretical depth; may extend to six chapters where the institution requires a separate Discussion chapter.
- PhD: same core progression, with expanded literature review (often theoretical + empirical + conceptual framework as distinct sections), more rigorous methodology justification, and a more substantial contribution-to-knowledge statement.

**End matter:** References, Appendices.

## Rigour scaling
Depth of literature engagement, methodological justification, and analytical rigor scale with the confirmed degree level — do not apply PhD-level expectations to an undergraduate project or vice versa. Ask the degree level before drafting if not already stated.

## Institution override
If the user supplies their own institutional template (e.g. their own university's postgraduate school format), follow it exactly for structure, ordering, and required sections, and flag any point where the supplied template is ambiguous rather than guessing.

## Never
- Blend the default Nigerian-format skeleton with a supplied institutional template — one or the other, not a merge.
- Invent chapter content depth inconsistent with the confirmed degree level.
