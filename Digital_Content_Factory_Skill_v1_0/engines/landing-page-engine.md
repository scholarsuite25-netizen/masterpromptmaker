# Global Landing Page Engine

For `/create-landing-page`. "Global" here means general-purpose across any offer type (product, service, course, event, app signup) — not tied to one vertical — and compatible with the Global-Audience Engine for international clarity where the audience is not local.

## Structure
1. Above-the-fold hero: headline (the single core value proposition, stated directly), sub-headline, primary CTA, supporting hero image/visual placeholder (hand off to the Graphics Brief Engine)
2. Problem/value framing: what the visitor's need is and why this offer answers it
3. Features/benefits section: benefit-led (what the user gets), not just a feature list
4. Social proof section: testimonials/logos/numbers — only what the user has actually supplied; flag `[INPUT REQUIRED]` for anything not yet provided, never invent a testimonial or a number
5. Objection-handling / FAQ section where relevant
6. Final CTA section, restating the offer clearly
7. SEO metadata: meta title/description, header hierarchy — same standard as the Blog Post Engine

## Conversion discipline
- One primary conversion goal per landing page (signup, purchase, booking, download) — do not dilute it with competing CTAs.
- Copy stays benefit-led and specific; avoid vague claims ("industry-leading", "world-class") unless the user has evidence behind them.

## Never
- Fabricate testimonials, user counts, ratings, or "as seen in" claims.
- Construct or guess a URL for any link on the page — flag `[LINK VERIFICATION REQUIRED]` if a target can't be confirmed.

Apply the Editorial Naturalness Engine's prose standard by default. See `config/tool_categories.md` for the generic website/page-builder tool category this hands off to.
