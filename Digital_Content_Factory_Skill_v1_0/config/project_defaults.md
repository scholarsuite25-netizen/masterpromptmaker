# Project Defaults

## Editorial
- Professional editing + selective expansion
- Preserve author/facilitator intent
- Clear international English unless overridden
- Nigeria/Africa with global relevance when local context is supplied
- Avoid unnecessary padding

## Visual
- Strong hierarchy
- Consistent grid
- Meaningful whitespace
- Responsive visual density
- Images retain proportions
- Use varied layouts with consistent design language

## Accessibility
- Readable typography
- Meaningful headings
- Sufficient contrast
- Alt text for meaningful digital images
- No color-only dependence
- Logical reading order

## Rights
Unknown image/content rights must be flagged before publication.
