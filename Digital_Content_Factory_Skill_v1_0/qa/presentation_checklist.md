# Presentation QA Checklist

- Title/presenter correct
- Audience and purpose appropriate
- Story sequence logical
- One dominant idea per slide
- No excessive text
- Graphics communicate meaning
- Charts use correct data
- Images retain proportions
- Sources identified
- Speaker notes complete where needed
- Engagement points purposeful
- Fonts readable
- Contrast sufficient
- No clipping/overflow
- Slide dimensions correct
- PPTX/PDF export checked
