# Publication QA Checklist

- Masthead correct
- Publication name correct
- Volume/number/edition/date correct
- Logo correct
- Contents match final structure
- Feature hierarchy clear
- Headlines consistent
- Text flows correctly
- No text overflow
- Images correctly cropped
- Captions and credits present
- Sidebars/pull quotes aligned
- Grid consistent
- Typography consistent
- Rights verified
- Accessibility reviewed
- Final pages/export checked
